# TEEMA 1: ITIL

## Põhimõisted
1. **Teenus (Service)** — väärtuse loomise viis kliendile ilma konkreetsete kulude ja riskideta.
2. **SLA (Service Level Agreement)** — teenustaseme leping kliendi ja it-osakonna vahel.
3. **Intsident (Incident)** — IT-teenuse kavandamata katkemine või selle kvaliteedi langus.
4. **Probleem (Problem)** — ühe või mitme intsidendi teadaoleva või tundmatu põhjus.
5. **Muudatus (Change)** — mis tahes lisamine, muutmine või eemaldamine, mis võib mõjutada IT-teenuseid.

## Mida õppisin
Selle teema raames õppisin tundma ITIL-i (IT Infrastructure Library) raamistikku. Sain teada, kuidas hallata IT-teenuseid nii, et need vastaksid äri vajadustele, ja kuidas käituda siis, kui süsteemis tekib viga või kasutajate pöördumine.

## Näide elust
Koolis lakkas töötamast Wi-Fi võrk. See on **intsident**. IT-tugi tegeleb selle kiire lahendamisega. Kui aga Wi-Fi kaob igal teisipäeval samal ajal, on see juba **probleem**, mille juurpõhjust tuleb uurida.
